# ARZ AI — 公司網站

ARZ AI 是 2026 年 2 月成立於台灣的新創品牌，協助企業導入 AI 與流程自動化，減少重複性行政工作。首個產品方向為已推出的 SaaS 預約管理系統。

## 網站定位

- 對企業：說明流程自動化服務、預約管理產品與合作方式。
- 對預約者：提供可操作的互動示範；示範資料不會提交到後端。
- 對合作夥伴與新創審核：提供成立時間、所在地、實際產品階段、聯絡方式與英文說明。

## 技術與部署

純靜態 HTML / CSS / JavaScript，可部署至 Cloudflare Pages。建置指令留空，輸出目錄為網站根目錄 `/`。綁定網域 `arz-ai.stream` 時請在 Cloudflare Pages 專案的 Custom Domains 設定，並確認 DNS 與 HTTPS 已就緒。

## 設計

採日系繪本手帳風，和紙白 `#FFFCF6`、墨灰 `#3E3A39`，四色點綴 `#F2A497`、`#F6D27A`、`#A8D3E6`、`#B9DAA5`。平塗 SVG，手機優先，支援減少動態效果。

## 資訊準確性

頁面中的互動預約為展示用途。未提供正式公司登記編號、客戶數或營收資訊；請在取得可公開核實的資料後再新增。

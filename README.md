# ARZ AI — 公司網站

ARZ AI 是 2026 年 2 月成立於台灣的新創品牌，協助企業導入 AI 與流程自動化，減少重複性行政工作。首個產品方向為由既有預約工程模組逐步產品化的 SaaS 預約管理系統。

## 網站定位

- 對企業：說明流程自動化服務、預約管理產品與合作方式。
- 對預約者：提供可操作的互動示範；示範資料不會提交到後端。
- 對合作夥伴與新創審核：提供成立時間、所在地、實際產品階段、聯絡方式與英文說明。

## 產品與專案案例

- **初期 SaaS 方向**：LINE 預約入口、時段管理、審核與例外營業規則；不同產業的多企業設定能力持續產品化。
- **運動場地 LINE 預約**：既有電話與現場管理情境下，考慮場地時段、緩衝、衝突檢查、審核及舊系統銜接。
- **宮廟補財庫流程**：從紙本報名與人工核對，設計 LINE 表單、訂單狀態、付款資料整理與文書流程。
- **規劃中的 Claude API 應用**：自然語言需求理解、資訊整理與客服回覆草稿；排程與重要異動由規則與人員確認處理。

案例呈現團隊參與的工作場景與實作經驗，沒有虛構客戶姓名、上線日期、營收或節省人力比例，也不代表規劃中的完整多租戶 SaaS 已正式推出。

## 具體專案案例與 SaaS 產品化敘事

- [中文詳細案例](cases.html) ／ [English field notes](cases-en.html)
- **運動場地 LINE 預約**：週營業時間、場地與時段規則、前後緩衝、衝突防護、後台審核與既有系統資料匯出。已有相關程式模組與部署記錄；正式環境資料庫遷移及 LINE 真機驗收仍待確認。
- **宮廟補財庫線上報名**：LINE LIFF 報名、活動與名額管理、訂單與刷卡流程、結緣品配送、Excel 清冊與批次疏文 PDF。專案範圍的實作與多宮廟自助 SaaS 規劃須分開說明。
- **產品化主張**：從不同企業共通的「請求收集 → 規則檢查 → 人員審核 → 狀態追蹤 → 系統整合」萃取模組；多企業帳號與產業模板在產品化中。
- **商業化方向（規劃中）**：面向台灣中小企業的訂閱式 SaaS 加上必要的導入整合服務。沒有公開未核實的用戶數、營收、募資金額、節省工時或 ROI 宣稱。

ARZ AI 於 2026 年 2 月成立。上述案例是團隊的實際工程與產品設計經驗，不能直接推定完整多租戶 SaaS 已公開開放訂閱，也不能替代官方新創審核所需的可查核公司資料。

## 技術與部署

純靜態 HTML / CSS / JavaScript，可部署至 Cloudflare Pages。建置指令留空，輸出目錄為網站根目錄 `/`。綁定網域 `arz-ai.stream` 時請在 Cloudflare Pages 專案的 Custom Domains 設定，並確認 DNS 與 HTTPS 已就緒。

## 設計

採日系繪本手帳風，和紙白 `#FFFCF6`、墨灰 `#3E3A39`，四色點綴 `#F2A497`、`#F6D27A`、`#A8D3E6`、`#B9DAA5`。平塗 SVG，手機優先，支援減少動態效果。
